# Event Registration Template Index (Historical & Active)

## Overview
This document serves as the authoritative historical and operational index for all **17 standardized event templates** built into the USGA Event Registration Form Generator. It details each template's primary purpose, target audience, minor inclusion policy, exact field counts, and the complete enumerated sequence of fields configured in the Master Templates database (`setupTemplates` in `Code.gs`).
